# Roteiros de criativos — Waitless (ChatGPT)

Roteiros prontos para gerar artes **minimalistas** no ChatGPT e postar no **Instagram** e no **TikTok**.

## Como usar

1. Abra [`_base.md`](./_base.md) e leia as regras de marca e o template de prompt.
2. Anexe a logo oficial em todo prompt de imagem:
   - completa: [`assets/logo-waitless.png`](./assets/logo-waitless.png)
   - só ícone: [`assets/logo-icone.png`](./assets/logo-icone.png)
3. Escolha o nicho:
   - [Salões e barbearias](./saloes.md)
   - [Clínicas e consultórios](./clinicas.md)
   - [Restaurantes e lanchonetes](./restaurantes.md)
   - [Serviços com fila](./servicos-fila.md)
4. Copie o **Prompt ChatGPT** do criativo.
5. Cole no ChatGPT (modo de imagem) **com a logo anexada**.
6. Use a caption do canal (IG ou TikTok).
7. Publique em **9:16**.

## Checklist antes de postar

- [ ] Arte em 9:16 (Reels / TikTok)
- [ ] Logo = arquivo oficial (não redesenhada pelo ChatGPT)
- [ ] No máximo 1 headline + 1 linha de apoio na imagem
- [ ] Cores navy `#0A1B3F` e laranja `#FF6600` (ou off-white `#F8F9FA`)
- [ ] Sem preço inventado, sem garantia falsa
- [ ] CTA aponta para [waitless.solutions](https://www.waitless.solutions)
- [ ] Caption do canal certo (IG ≠ TikTok)
- [ ] Público = dono / recepção do nicho

## O que este pacote não inclui

Mídia final, música nominada, anúncios pagos nem calendário editorial. Só roteiro + prompt + caption.
